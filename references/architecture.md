# DS-VISION 架构

DS-VISION 由一个 MCP 工具、一个动作路由器、浏览器适配器、提示词编译器、证据处理器、坐标映射器、视频帧规划器和本地会话注册表组成。

```text
/DS-VISION
    -> ds_vision (唯一 MCP 工具)
        -> action 路由器
            -> 浏览器视觉会话 -> 可见最终回答 -> evidence packet
            -> 视频 PTS 规划 / 坐标映射 / 会话 / 健康 / 校准
```

## 组件职责

| 组件 | 职责 | 不承担的职责 |
| --- | --- | --- |
| `ds-vision-mcp.mjs` | 注册一个 `ds_vision` 工具并返回结构化结果 | 不注册其他工具或命令 |
| `engine.mjs` | 校验请求、路由动作、执行隔离 A/B 与条件仲裁、写入本地服务记录 | 不从像素推断 DOM 或源码 |
| `browser-adapter.mjs` | 核验登录、视觉模式、DeepThink、上传和可见最终回答 | 不读取隐藏推理 |
| `prompts.mjs` | 编译阶段化证据提示词 | 不决定 Agent 的任务分解或停止条件 |
| `evidence.mjs` | 生成可审计 packet、提取归一化视觉原语、带状态标记的可见 claim 与通过严格帧/PTS 校验的静态视频 claim、执行共识对齐 | 不从其他未标记文本虚构 claim ledger |
| `coordinates.mjs` | 在显式测量链中转换坐标 | 不生成点击、DOM 或代码位置结论 |
| `video.mjs` | 固定时间采样、PTS manifest 与加密区间请求 | 不从未见内容选择时间间隔 |
| `session-registry.mjs` | 原子保存可恢复会话元数据 | 不保存凭据或隐藏推理 |

## 数据边界

浏览器适配器将用户提供的媒体和编译提示词提交至视觉服务。独立任务默认在 A、B 隔离对话中观察相同材料；存在需仲裁的 claim 时，C 带着原图和候选命题重新取证。适配器只读取生成完成后新出现且稳定的可见最终回答。证据处理器保存该可见回答的哈希、媒体标识、可见坐标原语和告警。浏览器登录态保存在持久档案，独立于可审计记录；运行日志不写凭据。

每个运行结果明确区分：视觉可见事实、图像候选、运行时测量需求和未知项。任何代码、DOM、网络或业务结论必须由调用 Agent 通过相应工具独立取得。
