# DS-VISION 单一入口约定

使用者只通过 `/DS-VISION` 发起服务；它是唯一允许配置的全局斜杠别名。

`/DS-VISION` 接收自然语言目标和可选材料。服务根据目标选择 `analyze`、`followup`、`compare`、`video`、`map`、`sessions`、`health` 或 `calibrate` 动作。动作是同一入口的内部路由参数，不形成额外的用户命令。

MCP 层只注册 `ds_vision` 一个工具。调用方将动作与参数放入该工具的结构化请求中；服务返回可审计的结构化结果与面向调用方的摘要。MCP stdio 配置没有通用的宿主斜杠命令注册字段，因此本目录不声称自动创建 `/DS-VISION`；部署者在宿主支持别名时只映射这一项，并在宿主内核验。

保持入口一致：

- 文档、示例、报错和日志使用 `DS-VISION` 大写名称。
- 不创建 `/vision`、`/followup`、`/video`、`/compare` 或其他全局斜杠命令。
- 不以工具名、动作名或文件夹名暗示另一个用户入口。
- 技能目录和包标识 `ds-vision-v3` 仅供本地发现与运行时引用，不是使用者命令。
